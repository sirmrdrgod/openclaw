# Finance Diagrams

Process maps, RACI charts, operating model diagrams, and value stream maps.

## What goes here

- Mermaid flowcharts for finance processes (approval flows, close cycles)
- RACI matrix diagrams
- Operating model layer diagrams
- Exported Draw.io files for presentation-quality versions

## Workflow

1. Document the process in `03-processes/<slug>.md` first.
2. Identify the key flow or decision points to visualize.
3. Use `mermaid-brain` templates to generate valid Mermaid syntax.
4. Embed the Mermaid code block in a `.md` file here.
5. Reference the diagram from the process file.

## Naming

`<process-or-topic-slug>-<diagram-type>.md` — for example `budget-approval-flowchart.md`, `ocfo-operating-model.md`.
