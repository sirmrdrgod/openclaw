# Finance Processes

Each file in this folder documents a specific finance or operating model process.

## Suggested file structure

```
## Purpose

What this process achieves.

## Trigger

What starts this process (event, schedule, request).

## Steps

1. Step one — who does it, what tool or form is used
2. Step two
3. Step three

## RACI

| Activity | Responsible | Accountable | Consulted | Informed |
|----------|-------------|-------------|-----------|----------|
| ...      | ...         | ...         | ...       | ...      |

## Controls

Key controls that apply at each step (approval gates, reconciliation points, audit trail).

## Diagram

See: [diagram](../04-diagrams/<slug>.md)

## Related topics

Links to `02-topics/<slug>.md` files.
```

## Naming

Lowercase kebab-case: `budget-approval-flow.md`, `month-end-close.md`, `capex-request.md`.
