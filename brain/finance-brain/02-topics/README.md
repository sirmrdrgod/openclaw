# Finance Topics

Each file in this folder covers one financial concept, domain area, or operating model element.

## Suggested file structure

```
## Definition

One paragraph defining the concept in plain language.

## Scope

What this topic covers and what it does not.

## Key elements

- Element 1 — brief description
- Element 2 — brief description

## Maturity indicators

How to recognize whether this area is functioning well or is underdeveloped.

## Related processes

Links to `03-processes/<slug>.md` files.

## References

- [Source name](../01-sources.md#section) or external URL
```

## Naming

Lowercase kebab-case: `cost-governance.md`, `tbmo-overview.md`, `investment-management.md`.

## Suggested starter topics

- `ocfo-mandate.md` — scope, accountabilities, and decision rights of the OCFO
- `tbmo-overview.md` — what TBMO is, its components, and how to implement it
- `cost-governance.md` — cost classification, thresholds, approval flows
- `investment-management.md` — portfolio tracking, business case standards, benefits realization
- `financial-controls.md` — key controls, SOD, reconciliation, audit trail
