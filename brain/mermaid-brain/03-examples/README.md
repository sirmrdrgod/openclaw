## How to contribute an example

1. Build the diagram using a template from `../02-templates/`.
2. Verify it renders correctly in GitHub Markdown preview.
3. Add the file here with a descriptive name.
4. Add a row to the index table above.
5. Include a brief explanation of what the example demonstrates at the top of the file.
