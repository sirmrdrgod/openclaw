# Research Sources

Trusted sources for public and free scientific research. Add a row when you rely on a source regularly.

## How to add a source

1. Verify it is publicly accessible (no paywall for the content you are using).
2. Add a row with name, URL, and a one-line scope note.
3. If the source relates to a specific topic, cross-link from `02-topics/<slug>.md`.
