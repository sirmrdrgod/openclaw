# Research Papers

Each file in this folder summarizes one paper or a tight cluster of related papers.

## Suggested file structure

```
## Citation

Author(s), year. Title. Venue. URL.

## Problem

One paragraph describing what problem the paper addresses.

## Approach

One paragraph describing the method or solution.

## Key findings

- Bullet 1
- Bullet 2

## Relevance

Why this paper matters to this research brain or to a linked topic.

## Links

- Topic: [topic name](../02-topics/<slug>.md)
- Diagram: [diagram name](../04-diagrams/<name>.md)  ← if applicable
```

## Naming

`<year>-<short-title>.md` — for example `2017-attention-is-all-you-need.md`.
