# Research Diagrams

Diagrams that visualize research concepts, model architectures, or data flows found in the literature.

## What goes here

- Mermaid source files for research-related diagrams
- Exported images (PNG, SVG) from Draw.io or similar tools
- Annotated screenshots from papers (with citation)

## Workflow

1. Draft the diagram concept in plain text or a topic file.
2. Generate Mermaid source using `mermaid-brain` templates and prompts.
3. Save the final `.md` here with the Mermaid code block embedded.
4. If a Draw.io export is needed, note the export path or attach the `.drawio` file here.

## Naming

`<topic-slug>-<short-description>.md` — for example `transformer-encoder-decoder.md`.
