# Research Topics

Each file in this folder covers one topic area. A topic file typically contains:

- A one-paragraph overview
- Key concepts or terms
- Links to relevant papers in `03-papers/`
- Links to trusted sources in `01-sources.md`

## Naming

Use lowercase kebab-case: `transformer-architectures.md`, `federated-learning.md`.

## Status tags (optional)

Add one of these at the top of a topic file:

- `status: stub` — placeholder, barely filled in
- `status: draft` — partially researched
- `status: current` — actively maintained
- `status: archived` — no longer actively updated
