# Architecture Topics

Each file in this folder covers one pattern, concept, or architectural style.

## Suggested file structure

```
## Overview

One paragraph describing the pattern or concept.

## When to use

- Condition 1
- Condition 2

## When not to use

- Anti-pattern 1

## Key components

Brief description of the main moving parts.

## Trade-offs

| Pro | Con |
|-----|-----|
| ... | ... |

## References

- [Source name](../01-sources.md#section) or external URL
- Related system: [system name](../03-systems/<slug>.md)
```

## Naming

Lowercase kebab-case: `event-sourcing.md`, `strangler-fig.md`, `saga-pattern.md`.
