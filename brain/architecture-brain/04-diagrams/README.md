# Architecture Diagrams

Mermaid source files and exported images for system and component diagrams.

## What goes here

- C4 context, container, and component diagrams (Mermaid source)
- Data flow and sequence diagrams for system interactions
- Deployment and infrastructure topology diagrams
- Exported Draw.io files or PNGs for presentation use

## Workflow

1. Identify the system or pattern you need to visualize.
2. Use the templates and rules in `mermaid-brain` to generate valid Mermaid syntax.
3. Save the `.md` file here with the Mermaid code block embedded.
4. Reference the diagram from the relevant `03-systems/` or `02-topics/` file.

## Naming

`<system-or-topic-slug>-<diagram-type>.md` — for example `api-gateway-context.md`, `event-flow-sequence.md`.
